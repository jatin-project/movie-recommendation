🎬 CineMatch – Movie Recommendation System

CineMatch is a web-based movie recommendation system designed to help users discover movies based on their preferences and interests.

✨ Features
🎥 Movie recommendations based on similarity.
🔍 TF-IDF and Cosine Similarity algorithm.
📂 Supports custom movie datasets using CSV files.
⚡ Browser-based recommendation engine.
🌐 Frontend-only mode – no backend required.
🐍 Optional Python Flask backend for live recommendations.
📊 Supports movie titles, genres, release years, and descriptions.
🛠️ Technologies Used
HTML
CSS
JavaScript
Python
Flask
TF-IDF
Cosine Similarity
🚀 How to Run
Download or clone this repository.
Open the frontend folder.
Add your dataset as data/data.csv.
Run python -m http.server 8000.
Open http://localhost:8000 in your browser.
🎯 Project Goal

To make movie discovery easier through content-based filtering and a simple, user-friendly interface.
